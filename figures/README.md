# Figures

Generated by `src/mp_analysis.py`. Regenerate with:

```bash
cd .../src
python mp_analysis.py --data ../data/all_stocks_5yr.csv
```

To customize which eigenvectors or stocks are plotted, see the command-line options table in the main `README.md`.

## Contents

- **`correlation_heatmap.png`** - Pearson correlation matrices for a small subset of stocks spanning consumer staples (KO, PEP, MDLZ), tech (AAPL, MSFT, GOOGL), and energy (XOM, CVX), so all correlation is visible.

- **`eigenvalue_spectrum.png`** - Full eigenvalue spectrum of the S&P 500 correlation matrix (asinh y-scale), plotted against the Marchenko-Pastur upper and lower bounds. Eigenvalues inside the shaded bounds are consistent with pure noise. Eigenvalues above the upper bound represent statistically significant correlation.

- **`eigenvector_{index}_chart.png`** - Bar chart of top loadings in eigenvector {index} (default: 10, 12) sorted by loading magnitude. Each bar is labeled with its ticker, so the top-loading stocks are directly visible. Each stock is color coded by industry using GICS sectors.

- **`eigenportfolio_{N}_vs_{tickers}_performance.png`** - Cumulative return series of the eigenportfolio built from eigenvector `{N}` (default: 10), plotted against the individual stocks in `{tickers}` (default: LEN, MHK, NWL). Stocks with large same-sign loadings in this eigenvector tend to move together. The vertical lines mark dates of 3-day price swings in the plotted stocks. When those stocks share the same sign and have high loadings on this eigenvector, the eigenportfolio typically shows a corresponding move on the same date. To see more about eigenportfolios, visit the associated paper mentioned in the main `README.md`.
